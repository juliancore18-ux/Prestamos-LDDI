# Préstamos Local LDDI

## Descripción

**Préstamos Local LDDI** es un módulo de gestión de préstamos con almacenamiento local, desarrollado 
para administrar el préstamo de equipos de cómputo y proyectores pertenecientes a los
Laboratorios Divisionales de Docencia e Informática (LDDI).

El sistema está dirigido a estudiantes y personal académico de la
División de Ciencias Sociales y Humanidades, facilitando el registro, 
consulta y control de los préstamos de equipos de manera sencilla y organizada.

## Características

- Registro de préstamos de equipos de cómputo y proyectores.
- Almacenamiento local de la información.
- Consulta de préstamos registrados.
- Interfaz sencilla e intuitiva.
- Gestión de datos mediante archivos locales.

## Tecnologías utilizadas

- Python
- JSON (almacenamiento de datos)
- Microsoft Excel (apoyo para la gestión de información)
- PyInstaller (generación del ejecutable)

## Uso

1. Clone el repositorio:

```bash
git clone https://github.com/juliancore18-ux/Prestamos-LDDI.git
```

2. Entre a la carpeta del proyecto:

```bash
cd Prestamos-LDDI
```

3. Ejecute el programa:

```bash
python prestamos_v2.py
```
